#诡异巫术：纯黑收割者

这是一个 Minecraft 模组，名为“诡异巫术：纯黑收割者”。

## 功能介绍
- 新增神秘生物“纯黑收割者”
- 添加暗黑系魔法道具与合成配方
- 支持 Forge/Fabric 加载器

## 安装方法
1. 下载对应版本的 `.jar` 文件
2.放入`.minecraft/mods`文件夹
3. 启动游戏即可生效

## 依赖项
- Minecraft 1.20.1+
- Forge 47.2.0+ 或 Fabric 0.15.0+
